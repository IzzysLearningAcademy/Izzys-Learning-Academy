# Izzys-Learning-Academy
Izzy's Learning Academy: Kindergarten to Grade 8 practice in Math, ELA, STEM and games. An independent supplemental learning platform, not an accredited school.

The site is published from `main` with GitHub Pages. Every pull request and every push to `main` runs the browser checks in `tests/ci/site_test.js`. Real iPhone and iPad checks are done by hand.
